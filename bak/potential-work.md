# QoS optimization and prediction

*   **MLCIMO (Machine Learning-enhanced Classification for Interference Management and Offloading):** The performance of this interference mitigation xApp was assessed using the **ns-3 network simulator** (specifically the mmWave module) rather than physical hardware.
*   **The REAL Framework:** While this is a full-stack O-RAN solution, it was tested in a virtualized environment using **simulated srsUE** instances connected via **ZeroMQ**. The authors explicitly note that the setup faces a "communicational limit" where the channel saturates if more than three UEs transmit simultaneously, distinguishing it from a hardware-based testbed.
*   **ScalO-RAN:** This energy-aware scaling system was prototyped on an OpenShift cluster, but the data used to profile its latency models was generated by an **E2 traffic generator** utilizing pre-existing datasets rather than live traffic from commercial smartphones.

*   **Transformer-Based Wireless Traffic Prediction (Habib et al.):** This framework was evaluated exclusively using the **MATLAB 5G Toolbox** to emulate traffic patterns for a dense urban area.


Sources that **have** been validated with real COTS hardware:
*   **xSlice:** Validated on a testbed serving **10 COTS smartphones** from brands including OnePlus, Google Pixel, Motorola, and Samsung.
*   **EExApp:** Deployed on a real-world 5G O-RAN testbed with a commercial radio unit and **8 smartphones**.
*   **DL-DRA (Bottleneck-Based Resource Allocation):** Validated using **8 physical devices**, specifically four laptops and **four mobile phones** equipped with 5G modems.
