The **Open RAN Commercial Traffic Twinning Dataset** (`wineslab/open-ran-commercial-traffic-twinning-dataset`) contains key performance metrics (KPMs) collected across different cellular layers and entities (Base Station, User Equipment, Application layer) using Open RAN / srsLTE software (via SCOPE).

The parameters available in the dataset depend on the specific CSV file:

---

### 1. PHY & MAC-Layer Base Station Metrics (`<IMSI>_metrics.csv` & `ue_metrics.csv`)

These files capture per-UE physical and MAC-layer radio metrics exported by the base station or measured at the UE side:

* **`Timestamp`**: Logging timestamp for the observation entry.
* **`num_ues`**: Total number of active UEs connected to the cell.
* **`IMSI`**: International Mobile Subscriber Identity (unique subscriber ID).
* **`RNTI`**: Radio Network Temporary Identifier (temporary link layer ID).
* **`slicing_enabled`**: Network slicing status flag (`1` if enabled, `0` if disabled).
* **`slice_id`**: Network slice assignment (`0` for eMBB, `1` for URLLC).
* **`slice_prb`**: Physical Resource Blocks (PRBs) allocated to the target slice.
* **`power_multiplier`**: Transmit power scaling factor.
* **`scheduling_policy`**: MAC scheduling algorithm used (`0`: Round Robin, `2`: Proportionally Fair).
* **`dl_mcs`**: Downlink Modulation and Coding Scheme index.
* **`dl_n_samples`**: Number of downlink measurement samples in the logging interval.
* **`dl_buffer [bytes]`**: Downlink buffer occupancy size (bytes) in the queue.
* **`tx_brate downlink [Mbps]`**: Transmitted downlink bitrate (throughput in Mbps).
* **`tx_pkts downlink`**: Total downlink packets transmitted.
* **`tx_errors downlink (%)`**: Downlink packet error/retransmission percentage (BLER).
* **`dl_cqi`**: Channel Quality Indicator reported by the UE (0–15 scale).
* **`ul_mcs`**: Uplink Modulation and Coding Scheme index.
* **`ul_n_samples`**: Number of uplink measurement samples in the logging interval.
* **`ul_buffer [bytes]`**: Uplink buffer backlog size in bytes.
* **`rx_brate uplink [Mbps]`**: Received uplink throughput in Mbps.
* **`rx_pkts uplink`**: Total uplink packets received.
* **`rx_errors uplink (%)`**: Uplink packet error percentage.
* **`ul_rssi`**: Received Signal Strength Indicator on the uplink (dBm).
* **`ul_sinr`**: Signal-to-Interference-plus-Noise Ratio on the uplink (dB).
* **`phr`**: Power Headroom Report from the UE.
* **`sum_requested_prbs`**: Total PRBs requested by UEs during the interval.
* **`sum_granted_prbs`**: Total PRBs actually granted/allocated by the base station scheduler.
* **`dl_pmi`**: Precoding Matrix Indicator (MIMO beamsteering parameter).
* **`dl_ri`**: Rank Indicator (supported spatial MIMO layers).
* **`ul_n`**: Uplink channel noise estimate sample count.
* **`ul_turbo_iters`**: Average Turbo decoder iteration count for uplink signals.

---

### 2. Aggregated Base Station Metrics (`enb_metrics.csv`)

These capture cell-wide summary statistics across all served users:

* **Downlink Bitrate Aggregate (`[Mbps]`)**: Combined downlink throughput across all slices and UEs.
* **Uplink Bitrate Aggregate (`[Mbps]`)**: Combined uplink throughput across all slices and UEs.

---

### 3. Application-Layer Metrics (`mgen.csv`)

Generated by the MGEN synthetic traffic generator running at the UE/application layer:

* **`Time / Timestamp`**: Packet arrival timestamp.
* **`Flow ID`**: Traffic flow identifier.
* **`Sequence Number`**: Packet sequence ID for packet loss tracking.
* **`Latency / RTT`**: End-to-end delay (latency) experienced by traffic packets.
* **`Throughput / Rate`**: Instantaneous application-layer throughput.
* **`Packet Loss`**: Count or fraction of dropped/lost packets.
