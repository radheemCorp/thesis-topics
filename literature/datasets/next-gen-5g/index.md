The paper **"Beyond Throughput, The Next Generation: A 5G Dataset with Channel and Context Metrics"** (`3339825.3394938.pdf`) presents two sets of parameters: those logged in the **Real-World 5G Production Dataset** (collected via G-NetTrack Pro) and those generated by the **Synthetic 5G/mmWave ns-3 Simulation Framework**.

---

### 1. Production Dataset Parameters & Roles (Real 5G Network Traces)

* **`Timestamp`**: Logs the exact time each metric sample was recorded at 1-second granularity.
* **`Longitude` and `Latitude`**: Records GPS spatial coordinates of the mobile device for user location tracking.
* **`Velocity`**: Measures the movement speed of the device in km/h to capture mobility patterns (static vs. driving).
* **`Operatorname`**: Anonymised cellular network operator name.
* **`CellId`**: Identifies the specific serving base station cell connected to the mobile device.
* **`NetworkMode`**: Indicates the active mobile communication standard (e.g., 2G, 3G, 4G, or 5G).
* **`DL_bitrate` & `UL_bitrate`**: Measures the application-layer download and uplink throughput in kbps.
* **`State`**: Tracks the activity state of the download process (`I` for idle, `D` for downloading).
* **`Pingavg`, `Pingmin`, `Pingmax`, `Pingstd`, `Pingloss`**: Latency statistics (average, min, max, standard deviation, and packet loss) measured via ping tests.
* **`SNR`**: Signal-to-Noise Ratio (in dB), reflecting channel condition quality.
* **`RSRQ`**: Reference Signal Received Quality (in dB), representing the ratio of RSRP to RSSI to gauge signal quality under interference.
* **`RSRP`**: Reference Signal Received Power (in dBm), measuring cell coverage and signal strength across reference symbols to assist in cell selection.
* **`RSSI`**: Received Signal Strength Indicator (in dBm), capturing wideband power including serving cell power, noise, and interference.
* **`CQI`**: Channel Quality Indicator (0–15 index) provided by the UE to guide the base station in selecting the optimal Modulation and Coding Scheme (MCS) for maximum achievable throughput.
* **`NRxRSRQ` & `NRxRSRP`**: RSRQ and RSRP values of neighboring cells, used for handover prediction and multi-cell coverage analysis.

### 2. Simulation Dataset Parameters & Roles (ns-3 mmWave Framework Output)

In addition to client-side metrics, the synthetic ns-3 simulation logs base station and low-level scheduling parameters:

* **`time` / `simTime`**: Simulation time index in seconds.
* **`frame` & `subF`**: 5G radio frame number and subframe index for frame-level timing.
* **`1stSym` & `symbol#`**: Starting symbol index and allocated symbol count within a slot.
* **`cellId`**: ID of the serving base station.
* **`rnti`**: Radio Network Temporary Identifier assigned to uniquely identify a UE within a cell.
* **`ccId`**: Component Carrier ID for carrier aggregation setups.
* **`tbSize`**: Transport Block Size, indicating the data payload size per transmission time interval.
* **`mcs`**: Modulation and Coding Scheme index assigned by the scheduler.
* **`rv`**: Redundancy Version index used for HARQ retransmissions.
* **`SINR(dB)`**: Signal-to-Interference-plus-Noise Ratio at the receiver.
* **`corrupt`**: Binary indicator (0/1) showing if a transport block suffered packet corruption.
* **`TBler`**: Transport Block Error Rate, tracking transmission error probability.
* **`UE`**: Unique identifier for the simulated user equipment node.
* **`CurXPos`, `CurYPos`, `CurZPos`**: 3D Cartesian spatial coordinates of the UE in the simulation space.
* **`CurXVel`, `CurYVel`, `CurZVel`**: Velocity vectors of the UE along the X, Y, and Z axes.
* **`CalcClosestENB` & `CalcClosestEnbDist`**: ID of the closest base station and the calculated physical distance to it.
* **`enbX`, `enbY`, `enbZ`**: 3D spatial coordinates of the base station.
