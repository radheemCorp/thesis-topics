# AGENTS.md — docs/

Scope: user-facing documentation, never source of truth for behaviour.

## Layout
- `usage/` — CLI, running xApps, running CMC, synthetic datasets, scenarios.
- `reproduction/` — research-fidelity report, presentation outline, and the
  ICP-semantics / testbed-data analysis for the Wadud (`2311.13389v1`) vs QACM
  (`2405.07324v2`) comparison.
- `synthetic/` — scenario descriptions and generated figures.
- `visualizations/` — rendered plots (outputs, not inputs).

## Rules
- Docs must match `cli/cli.py` and `surrogate_xapps/runner.py`; update in the same change as the code.
- Keep runnable commands in fenced blocks using `uv run …`.
- Figures in `visualizations/` are generated by `scripts/` — do not hand-edit; regenerate.
- One concept per file; link rather than duplicate.
